Entry for the make.fun bounty [How Many Tabs Do You Have Open?](https://make.fun/bounty/u-danu-how-many-tabs-do-you-have-open-d86e783d).

The entry is a single number, exactly as the bounty requires:

> 137

The judge weighs whether the count is surprising yet believable as an honest answer, and whether it hints at a life behind it without a word of explanation. 137 is high enough to surprise and specific enough to read as counted rather than invented — round numbers read as guesses, meme numbers read as jokes — while staying well inside what a real tab hoarder honestly runs.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.txt
```

`main.py` validates the entry against the bounty gate (UTF-8 text of 1 to 5 characters, digits and nothing else) before writing it to `entry.txt` in the output directory (`/output` by default, as in the grader).
